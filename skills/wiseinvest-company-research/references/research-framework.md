# 研究框架

按具体生意选择问题，避免逐项照抄。先形成对企业整体的理解，再决定主线和详略。

## 一笔生意与企业价值

- 区分使用者、采购决策者、付款者，解释需求从何而来及预算约束。
- 说明客户买的是设备、产品、服务、使用权、交易撮合还是风险承担；明确交付、计费单位、续费及复购方式。
- 分析客户自己做、换一家供应商、使用不同技术或不购买的可行性。将节省成本、时间、风险或创造收入的价值说清楚。
- 分开检验产品有用、客户愿意持续付款、企业能够保留利润三个命题。
- 多业务公司区分收入主体、利润来源、现金消耗和股权投资；尊重合并范围，避免归入参股企业全部收入或重复计算权益价值。
- 用公开可核验的交易展示机制。资料不足时使用清楚标注的假设案例，不捏造客户故事、合同条款或利润。

## 塑造今天的关键历史

选择改变商业机制的转型、收购、产品、渠道、融资、扩张或失败。

对每次关键决定解释当时的问题、可选路径、成本和代价，以及今天保留下来的能力、协同、债务、整合负担或限制。优先评价执行、激励和资本配置记录；避免从后来的成功倒推过去每一步都正确。

## 收入、利润、现金与增长限制

选择能解释业务的收入关系，例如销量与单价、客户与客单价、交易额与收费率、产能与利用率。把简化公式当作解释工具，披露遗漏项，不伪装成完整预测模型。

- 区分随业务量变化的成本、需要提前承担的固定成本、维持现有业务的投入和新增业务的投入。
- 说明规模扩大是否降低单位成本，以及降本是否被价格竞争抵消。
- 对照收入确认与收付款时间，检查应收账款、库存、应付和客户预付款。
- 区分客户增加、使用量、提价、份额、行业景气和并购带来的增长；检查可比口径。
- 判断当前限制主要来自需求、客户预算、供给、技术、良率、交付、人才、融资或其他因素。
- 解释债务到期、利息、股权激励、增发、回购及并购如何影响每股收益与现金权益。

持续区分卖得更多、赚得更多和产生更多现金。不可仅从其中一项推导另外两项。

## 竞争优势与价值分配

把技术、品牌、生态、网络效应或规模的说法转成可核验的问题：

- 客户为什么续费、复购或扩大使用？转换需要多少成本、时间和风险？
- 竞争者复制能力需要什么投入？替代方案能否以不同方式解决同一问题？
- 优势是否表现为价格、成本、留存、份额或资本回报？证据是否跨越了一个特别有利的供需时期？
- 上游、客户和渠道能否拿走大部分新增收益？客户的投资回报能否支持继续采购？
- 供需缓和、技术更新或客户集中度提高时，当前优势能保留多少？

明确供应商、客户、渠道、竞争者及可能的多重角色。不要用行业空间、知名合作伙伴、热门设备、专利数量或管理层自述单独证明护城河。

## 当前阶段及证据门槛

分别观察业务阶段、财务阶段、行业阶段和市场预期。不同业务可以处于不同阶段；阶段可以倒退。没有足够材料时保留判断。

| 待判断事项 | 优先寻找的证据 | 仍不足以证明的材料 |
| --- | --- | --- |
| 产品获得认可 | 持续付款、复购、续费、扩大使用及客户获得的价值 | 试用、意向、签约仪式、合作公告 |
| 商业模式跑通 | 交付成本、留存、单位经济性、回款及必要的更新投入 | 仅有收入或单个高毛利项目 |
| 能够规模复制 | 新客户、新地区或新产能重复成功，成本和交付质量可控 | 只有一个客户或项目成功 |
| 能持续产生现金 | 跨期利润转化、维护投入与营运资金表现 | 某期大额预付款、资产出售或付款延后 |

在阶段判断中回答：已经证明什么、没有证明什么、下一阶段需要什么条件、哪些证据会改变判断。不要凭空设置精确阈值。

观察行业的渗透率、客户预算、价格、供给、产能交付、利用率及库存，区分企业自身改善与行业周期推动。涉及股票时另行评估价格已包含的预期。

## 按行业选择重点

下表仅用于选择相关指标。解释定义、口径和适用限制，避免为每家公司机械收集整张表。

| 业务类型 | 可优先检查的关系与证据 |
| --- | --- |
| 半导体、存储和硬件 | 销量、价格、产品组合、库存、产能、良率、利用率、客户预算、交付与资本投入；区分设计公司和自建产线模式，检验景气与持续竞争力 |
| 软件与订阅 | 付费及使用量、续费和留存、扩购、折扣、获客与服务成本、回款、股权激励；核实 ARR 和 RPO 的定义、确认节奏，不能直接等同收入或现金 |
| 云、数据中心、电力等资本密集业务 | 合同质量、客户信用、可交付能力、利用率、建设周期、供电或许可限制、维护与增长投入、融资成本；区分公告规模和已投产能力 |
| 平台与交易业务 | 交易规模、收费率、补贴、履约成本、用户及商户留存、网络效应；区分总额法与净额法、撮合流量与利润 |
| 银行与金融机构 | 资产负债结构、存贷款及融资成本、净息差、信用损失、资本充足、流动性与适用回报指标；不要套制造业净债务或普通企业自由现金流框架 |
| 消费、零售和服务 | 销量、价格、复购、渠道、同店表现、单店投入与回收、库存及营运资金；检查品牌溢价与扩张能否复制 |
| 资源与周期行业 | 价格、产销量、成本曲线、储量、维护投入和供需响应；避免用周期顶点利润直接外推长期价值 |
| 控股和多业务集团 | 分部经营、内部资金转移、少数股东、参股权益、母公司债务和资本配置；进行分部估值时消除重复计算 |

## 反证与替代解释

优先检验最可能影响主判断的错误来源：

- 将行业景气当成企业竞争力，或将短期稀缺当成长久定价权。
- 将客户预付款、付款时点或资产出售当成持续经营造血。
- 将单个项目或大客户的成功当成规模复制能力。
- 将融资支持的扩张当成无需新增资本的增长。
- 将公司规模增长当成每股价值同步增长。

解释每项反证是否足以改变判断，不为平衡篇幅制造争议。用明确业务条件设定修正标准；合理依据不足时，不编造数字门槛。
