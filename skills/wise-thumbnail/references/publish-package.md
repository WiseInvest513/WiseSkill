# 完整视频发布套件

用于可上传完整视频的配套交付：默认自动完成，不等用户逐项提醒。制作顺序是先完成封面优化与检查，再写简介，简介后紧接真实章节目录；同时准备一个推荐发布标题。用户已确认的决定及本次明确范围优先。仅要标题、封面、字幕或局部样片时只做该项；明确只要视频时不扩大任务。

## 内容与次序

- 读取最终成片、校正字幕、最终时轴和当前封面反馈。封面沿用已确认的超大标题与右下角适度地球版式，默认制作16:9、3:4、4:3三张，各自排版与检查，尺寸见[Wise封面布局](wise-series-layout.md)；明确只要某比例或先看样稿时遵从本次范围。标题与简介共享本片实际主命题。发布标题依照 [发布标题与数据核验](publish-titles.md)，中文中长视频默认约30个可见字符（通常28–32个），必须含有依据的数字，并交代真实行动或处境、结果和观看价值。
- 简介默认200–300字：中文按字，英文字母、数字和标点各按可见字符计数，空白及章节目录不计入；用脚本核对长度，不靠估算。按本期内容自然引出最吸引人的具体命题，带入至少一项有来源的数据或条件，再提出值得验证的问题或点明反差，并说明视频真正讲解的价值。可以连贯写成一段，不把四部分变成机械句式；不能每期照搬某次选举、胜率或投资主题。
- 数据或条件须能回指已核验一手资料或用户原文中的适用条件，记录来源及对应片段。核验外部数据时沿用标题的数据核验口径。缺数据可用真实且有出处的适用条件，不捏造数字；无法证实的内容删去或说明缺口。问号不能替代统计样本、观察区间、买入窗口与持有期等必要限定；历史100%结果必须说明样本和条件，不暗示未来保证。
- 章节只列视频真实讲到的段落，从0:00起、按最终成片绝对时间递增，标题准确简短。拼接分段、插入开场/片尾、裁切或改速后，重新对照最终MP4及字幕核对各章起点与总时长；不直接复制分段相对时间，不按文稿猜时间，不虚构章节。未取得最终时轴时标明待核对，不能声称发布包已完成。

## 保存与直接交付

最终文字按“推荐标题 → 200–300字简介 → 章节时间目录”排列，简介后紧接章节；三种比例封面作为独立可上传文件一并交付（用户明确缩小范围时除外）。回复给出可直接复制的完整文字和实际文件，不只介绍写作方案。

- 完整文字统一保存为本期实际导出目录中的`介绍.txt`，例如`exports/<episode>/介绍.txt`；系列沿用既有系列/期目录。内容顺序固定为“标题→简介→真实章节”，默认不另建重复的发布包TXT。
- 封面：按期放入`exports/<episode>/`，采用“中文期数-主题-比例.jpg”，如`纳指投资第一期-买纳指到底买什么-3比4.jpg`；另两张分别标`16比9`、`4比3`。仅预览的样稿留在本期工作区。
- 默认不重复生成独立标题、简介或章节TXT。机器读取的章节JSON、字数与事实核验记录可放本期工作区或维护记录，不挤入可直接复制的`介绍.txt`。
- 在小型记录中保存标题与简介计数、数字/条件来源及最终时轴核对结果。已有确认文字需要保留时，按明确版本名保存新稿；用户授权替换后以`介绍.txt`作为当前完整文案。用户授权清理时，可删除被其完整替代的本期重复旧文案，不扩大到其他期、原件或已确认成片。未确认新封面保持candidate，不因发布包已生成就登记成approved模板。保存或交付不代表获准上传平台、发布或推送仓库。
