# Wise 三比例封面：第9期确认布局

用户于2026-10-30指定第9期为后续封面基准。顶部左侧为期数＋系列名＋本期主题；顶部右侧使用原始头像署名PNG。大标题左对齐、地球右下辅助，延续米白深蓝哑金。原始背景/头像素材不修改。

- 16:9=1920×1080；3:4=1200×1600；4:3=1600×1200，分别编排标题与行距。
- JSON输入：`episode`（无期数时省略）、`series`、`topic`、`footer`、`layout`、`variants[ratio].lines`及`scope`。各期文字必须替换，不能沿用示例标题或数字。
- 左上字号分级，红底黑字期数居左，系列名在主题上方，文案均左对齐；头像署名始终右上。顶部区域与大标题留出间距。
- 通过HTTP打开 `index.html?ratio=16x9&content=example-ep10.json`，等待`window.coverReady`，按真实画布JPG94导出。字体依赖本机PingFang SC；其他电脑使用合法相近硬朗字体并重新检查。
- 背景依赖见index.html相对路径及manifest；完整背景需GSAP和原品牌图。共享素材保持原件，内嵌背景原有署名在封面中隐藏，再按右上位置原样放置，不改视频背景模板。
- 每次导出检查3张全图及320px宽等比缩略图。旧2026-10-27模板保留作历史，不再默认用于新封面。
