# 去AI化规则

## 一、最常见的AI感来源

### 1. 过度工整

症状：

- 开头反差
- 三个编号
- 一个风险段
- 四个观察指标
- 一句排比金句

处理：删除一层结构；把一个编号改成连续叙事；让一段明显短于其他段。

### 2. 每段都在解释

症状：每个数字后面都有“这意味着”“这说明”“这一点非常重要”。

处理：有些数字只需放进句子；有些意义让读者自己感受到。

### 3. 正确废话

示例：

- 公司基本面依然强劲
- 机会和风险同时存在
- 未来值得持续关注
- 市场需要重新定价
- 长期价值仍需验证

处理：追问“具体是什么？”无法具体化就删除。

### 4. 强行平衡

症状：用户想写正面文章，最后三分之一突然全部讲风险。

处理：尊重倾向。风险只保留会改变判断的部分。

### 5. 假装真人

症状：机械插入“说实话”“哎？”“🤣🤣🤣”。

处理：口头表达必须和上下文自然相连，全文不超过合理频率。

## 二、句式上限

全文建议：

- “不是……而是……”不超过2次
- “真正……”不超过4次
- “这意味着”不超过1次
- “换句话说”不超过1次
- “综合来看”尽量不用
- 连续排比不超过1组
- 观察指标清单不超过3项，除非用户明确要求

## 三、人味重写动作

交稿前至少做四项：

- 删除一段完整但无辨识度的话
- 把一个抽象段落换成具体场景
- 保留一句用户原稿里略带口语甚至不完美的句子
- 合并两段过短、过整齐的段落
- 打散一个完美三段论
- 删除一个“金句式”结尾，换成自然判断
