# 段永平与“看懂”

类型：长帖-人物方法论  
核心：长期主义只是结果，“看懂”才是长期持有的前提。

## 结构

1. 从段永平近期科技股动作进入；
2. 网易：做过游戏，因此理解市场空间；
3. 苹果：做过消费电子，因此理解商业模式难复制；
4. 存储：产业经验帮助理解供需，但仍用卖 Put 控制边界；
5. “看懂”不是预知未来，而是知道公司靠什么赚钱、风险在哪里、什么价格愿意承担；
6. 普通人不能只抄仓位，要学习能力圈、研究和仓位边界。

## 代表句

“不是因为长期持有，所以最后赚到大结果；而是因为看懂了，所以才有能力长期持有。”

## 学习

人物稿用案例，不用名言；抽象方法最后回到普通人。
