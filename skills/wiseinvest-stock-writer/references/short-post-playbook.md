# 短帖写作手册

短帖不是压缩版长文，而是“情绪和判断的即时表达”。

## 六种短帖

### 1. 情绪行情型

入口先有反应：

- 鬼故事喽，这是真鬼故事……
- 好家伙，把港股当成山寨了。
- 这哪里是调整？这简直就是估值屠宰场。

随后立即给价格、跌幅、时间或事件，再提炼一个判断。

### 2. 引用反驳型

顺序：

1. 直接回应原帖；
2. 承认它在哪个阶段有效；
3. 指出当前阶段为什么不适用；
4. 给出一个更高层判断。

例如：

> 看财报当然是基础，但它更适用于市场尚未充分挖掘的时候。到了预期白热化阶段，财报好不等于股价涨，你还要判断价格里已经塞进了多少情绪。

### 3. 交易复盘型

写清：

- 当时怎么判断；
- 哪个位置做了什么；
- 为什么做对；
- 哪些仓位仍在抗；
- 后面哪里暂时看不懂。

目的不是晒战绩，而是展示判断过程。

### 4. 知识科普型

只讲一个概念，并立刻连接当前市场。

例如 PEG：

- 一句话定义；
- 为什么半导体特别重要；
- 一组当前数据；
- 一个反例：周期股 PEG 极低不等于无脑便宜。

### 5. 哲学长期主义型

从自己的工作、阅读或人物进入：

- 巴菲特、芒格、段永平；
- 《曾国藩传》；
- 《毛泽东选集》《邓小平选集》；
- 名人传记；
- 做投研、AI、网站、YouTube、直播。

最后落到：做长尾、做积累、做可复利、长期有价值的事情。

### 6. 人物动作点评型

重点不是某人买了什么，而是：

- 他的资金期限是什么；
- 为什么他敢买；
- 普通人缺少什么；
- 这笔动作能否作为买点。

## 节奏

第一屏必须有态度。

第一到第三段必须出现至少一个具体事实。

中间只展开一个不同判断。

结尾可用：

- 一个交易态度；
- 一个反问；
- 后面继续看；
- 下周开盘见；
- 大家心里要有判断；
- 一句有情绪的现实判断。

## 禁止

- 补完整行业背景；
- 四项观察指标；
- 五条风险；
- 备选标题＋来源大礼包；
- 为了专业把情绪磨平；
- 把短帖写成小论文。
