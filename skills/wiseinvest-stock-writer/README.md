# WiseInvest Stock Writer Skill 3.2

这一版不再把所有内容写成“财经长文模板”，而是明确分成三套写法：

- **短贴**：情绪、引用评论、行情判断、交易复盘、哲学与长期主义；
- **长帖**：财报、公司、产业、行情复盘、人物方法论；
- **广告合作稿**：真实使用场景、问题切入、自然推荐、合规表达。

## 安装

把解压后的文件夹改名为：

```text
wiseinvest-stock-writer
```

然后放进：

```bash
$HOME/.agents/skills/
```

最后应当是：

```text
$HOME/.agents/skills/wiseinvest-stock-writer/SKILL.md
```

重新启动 Codex。

## 短贴调用

```text
$wiseinvest-stock-writer

模式：短贴
类型：情绪行情型
素材：智谱从2980跌到890，MiniMax从1330跌到193
核心判断：AI有未来不等于任何估值都合理，跌80%也不自动便宜
要求：直接、有情绪，500字左右，不要来源
```

## 长帖调用

```text
$wiseinvest-stock-writer

模式：长帖
类型：财报拆解
选题：特斯拉Q2财报
核心问题：汽车业务还能不能养得起AI野心
倾向：短期谨慎，长期保留想象力
要求：2000字左右，有数据、有推论，不复述完整财报
```

## 广告调用

```text
$wiseinvest-stock-writer

模式：广告合作稿
选题：Bitget rToken
切口：上一篇讲一份钱三份用，这一篇回答背后是不是真实美股
核心：1:1只是起点，继续看托管、权属与审计
要求：像个人研究分享，不出现品牌材料或文件，1500字左右
```

## 改稿调用

```text
$wiseinvest-stock-writer

模式：改稿
目标：把下面的Codex稿去AI化
要求：保留我的原始观点和口语；删掉对称三段、四项观察和标准风险结尾；不要重写成研报

【粘贴原文】
```

## 推荐使用方式

Skill负责：查资料、核数据、找主线、出接近成稿的第一版。

最终稿仍建议结合你当下的仓位、情绪和市场判断，再做最后一轮人工修改。
