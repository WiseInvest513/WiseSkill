# 让动作承担含义

设计动作、修复“像幻灯片”或静态转动画时读。本文是随包维护的完整方法；不需要外部 Skill、作者工作区或某个付费插件。资产和构图交接见 [设计到动效](design-to-motion.md)，方法出处仅作 [可选参考](external-methods.md)。

## 从变化选动作

先在同一份 `semantic_plan.json` 中写清：**谁在何处 → 因什么变化 → 哪个可见维度改变 → 观众看到什么结果**。给动作一个稳定参照；只有开始和结束两个漂亮画面，还不能证明变化可读。

| 原文任务 | 可观察的动作或状态差 | 不能代替它的效果 |
| --- | --- | --- |
| 交付、传导、转入 | 对象从明确起点经过路径到接收者；接收方发生相应结果 | 两端各淡入一个副本，暗示没有发生过的转移 |
| 加入、退出、归属 | 同一对象穿过集合边界；成员数或归属发生变化 | 只改变整个面板透明度 |
| 增减、回撤 | 有依据的数值、长度或净值位置改变，并保留比较基准 | 让所有物件一起变大，或用钱包标签充当卖出/回撤 |
| 比较、选择 | 保持共同尺度和条件，依次突出对应差异或选中路径 | 无依据放大“更好”的一侧 |
| 打开、拆解、组成 | 独立部件围绕合理连接点展开，保留部件与整体关系 | 单张平面图大幅翻转成不存在的侧面 |
| 等待、维持 | 保留可读的当前状态及等待条件；若有数据时间线，才推进该时间线 | 为消除静止而添加漂浮、呼吸或无意义计数 |

关系线要有可读的端点、方向与必要短标签；“卖出 → 等待回撤 → 买回”必须能逐段辨认。不能用几条无标签曲线让观众自行猜动作。图中数量、成交、方向和因果均受原文约束。

## 用场内对象承接下一句

先判断旧对象是否仍有解释任务。需要保留时保持同一 `object_id` 和资产身份，改变角色或位置；任务结束时连同所属标签、连线一起退出。选择与内容对应的交接：

- **沿用参照**：上一句的结果留作下一句输入，新的关系围绕它建立。
- **进入细节**：放大已出现的部件或区域，保留来源提示；返回时恢复原参照。品牌字标不能被不合理拉伸。
- **传递结果**：对象先完成交付，再由接收方引出下一步；移动方向和到达位置连续。
- **替换焦点**：固定背景与共同框架，退去已完成的一组、展开下一组；真实话题切换可以直接切镜，不必生造因果。

不规定全片必须使用几种转场。连续镜头若反复使用同一整页淡入、上移或翻书，先检查是否遗漏了真实内容变化；变化来自任务，不能靠随机轮换特效制造多样性。

## 时间、缓动和阅读

以实际原声和原字幕划分“建立 → 主要变化 → 阅读 → 交接”。句级字幕不能提供词级落点；要卡准关键词时听该段并记录时间。原音频不因动画太满而加速或删句。

- 入场需要落稳，收尾可以较干净利落；镜头平移需平滑起止，恒定进度才用匀速。不要所有对象都套同一种时长和缓动。
- 简单短位移可从约半秒试起，再按距离、物件尺寸和旁白调整；复杂关系留足可追踪过程。这个起点不是验收阈值。
- 同级对象可略错开建立阅读次序；只有逻辑允许时才重叠前后动作。前一个结果尚不可读，后一个动作不能将其盖住。
- 标题与标签落位后保持稳定。文字、颜色和透明度不做无意义回弹；需要强调时改变相应对象或关系，不让整屏同时跳动。
- 稳定停留有阅读、比较或等待任务时是有效设计。背景自转、微弱漂浮不计作本句的语义动作；也不为了通过“持续运动”检查破坏必要停留。
- 简短结论和片尾也要有实际可读的停留窗口；长度以最终尺寸、文字密度和正速播放为准，不套用英语词数计算中文阅读时间。

## 引擎无关的实现约束

继续当前可用引擎；不因参考来自 HyperFrames、Remotion 或其他系统就迁移工程。位置、尺度、遮罩和原生 SVG 路径已能实现多数关系动作。SVG 路径揭示可用长度与 dash offset；沿路移动可用采样点或可用路径功能。只有确需且已可用时才选择额外插件。

所有属性由同一可定位时间轴决定：固定随机种子，提前完成异步素材加载，布局测量不放在每帧回调里，不让两个时间线同时写同一属性。正向播放、逆向 seek、直接定位到某时刻应得到相同状态。不能依赖鼠标、滚动、墙上时钟或上次播放残留。

模糊、景深和弹性只在有明确用途且引擎支持时使用。增加效果后复查实际编码帧；遮住文字或吞掉关键中间态就应减弱或移除，不能把效果数量当成运动质感。

## 如何证明动作完成

为关键动作记录实际时间点，查看前态、途中、后态和相邻转场；正速带原声播放。检查身份是否连续、路径是否可追踪、结果是否可读、是否穿字或出框，再检查同秒双向 seek。终态截图、代码里的目标值或只有背景在动都不足以通过。

若目标环境的 HyperFrames CLI 已提供相应能力，可额外检查关键帧/路径并添加 `.motion.json` 的 `appearsBy`、`before`、`staysInFrame` 等断言；先查已安装版本的帮助。`keepsMoving` 只用于计划明确要求持续动作的区间。该功能不是必装依赖，也不能把有意停留判成失败。没有它时用实际取帧与播放记录完成同一检查。

结构检查、语义动作、正速质感、声音落点分别记录 `passed / failed / not_verified`。脚本通过不能代替后三项。
