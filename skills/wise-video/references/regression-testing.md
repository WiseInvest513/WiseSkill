# 实际样片回归与调试

> 历史验证说明：文中的旧测试项目仅是当时的验证记录；原工作区已按用户要求精简归档，这些工程不随包提供，也不是运行依赖。新内容在本期工作区重新验证。

用户要求验证 Skill 时，不能只返回格式或链接检查。测试范围以本轮请求为准：只升级规则时在隔离目录做独立文案试用和代表镜头的实际静态图；需要验证动作才做局部运动测试；用户要求成片才导出对应范围。不要借旧授权擅自重渲染整条被否定的视频。

## 先固定可比条件

1. 指定旧版成片/计划、原文范围、同一原声、时长与素材索引，保留旧版本。
2. 先从原文重做角色和关系分析，再对照旧画面。记录旧版已经做到的事，不把已有动作算成新增改进。
3. 预先列3–5个可被推翻的判断：句间新增意思是否被漏掉、前句任务结束的载体是否退场、整屏焦点是否被背景装饰挤偏、角色是否错配、集合增多是否同质复制、载体是否到达、否定条件是否保留、是否跨句延续。
4. 背景/画质/配色更新单列，不把它们当成内容理解进步的证据。

## 按测试范围完成实际闭环

- 先固定观众任务和已接受风格：媒介/主视觉选择→真实静态图与主要展开态→实际看图→具体失败修正→复验，再按授权推进运动或成片。比起一口气给整片加图，先让代表镜头成立。语义和审美都可能失败，不能用排版无碰撞覆盖主视觉选错。
- 独立前向测试只给更新后的 Skill、原始新文案与必要素材，不预先告知预期答案。检查设计决策能否随内容变化；规划测试不能宣称成图或运动已经验证。
- 按 [同屏布局与元素退场](layout-and-lifecycle.md) 检查追加内容、缩放重排和交叉淡化。选择关键动作前、中、后时间点；不能只展示最漂亮的完成帧。检查实际对象，而非仅看验收描述写了什么。
- 可量化的关系测实际位置/成员可见数/载体连续性；不以代码中的目标值充当实测值。
- 修改一个计划动作确认输出会变；检查正向和逆向seek的一致性。保留原输入/计划哈希。
- 静态转动效时，检查 [设计交接](design-to-motion.md) 中的资产/布局依据、可动部件及主要动作证据。对照原字幕检查触发，并以局部原声样片验证重点动作的节奏与读图时间；未听取音频不冒称词级对齐。原声文件一致性和音频流检测不等于完整听审，记录实际听审范围。
- 导出后检查实际成片时长、音频、解码并抽帧；浏览器快照不能替代成片检查。

## 句间理解专项回归

当反馈是“乱、没有重点、每句没讲完、图不对题”，检查相邻句链而非只检查单张稳定帧。至少用实际失败类型及一个不应退场的对照：话题已转为受众/利益时清掉旧设备；同一传递流程仍依赖起终点时保留它们。判断每个状态能否复述本句新增意思，禁止仅凭coverage或无相交计为通过。

焦点接线升级用两类回归：旧“几乎所有对象都填focus”的记录应产生复核候选；合理的多对象比较/关系组有共同任务说明时应被容许。对有效ID却理由错配的记录，明确脚本无法识别，必须对照原句和实际图人工审阅。运行 `python3 -m unittest discover -s tests -p 'test_visual_audit.py'` 验证绑定扫描，另用本次失败图与修复图验证真正的层级变化；单元测试不证明审美。静态输出保留实际播放尺寸PNG，具体检查小字承托、重复时间信息及当前句焦点，动态未测时仍记未验证。

另用一段未见的新文案独立规划，检查焦点与退场决策是否随语义变化；不要向执行者预告应删谁、应采用何种布局。规则升级阶段可以只验证规划及隔离静态状态链；动态与编码结论留未验证，不擅自推进正片。屏幕文字支持验证需至少看一张带真实素材、背景和承托的画面；原视频、模板均不覆盖。

## 对比记录

每项写“时间段｜旧版可观察行为｜新版可观察行为｜原文依据｜证据文件｜通过/失败/未验证”。区分方法优化与本集具体实现，承認没有改善或出现新问题的项目。技术警告、失败首轮与修复过程保留。

方法迭代按 [失败回写](design-to-motion.md#6-把失败写回方法别把本集坐标写成规则) 记录触发条件、原因、实际修复、证据和不适用边界。先分辨实现错误与规则缺口，替换无效/重复规则，不把本期品牌、坐标写成强制模板。复查失败例和一个不会触发该规则的对照情形；旧内容回归只证明这个样例，跨主题能力仍需要新文案试用，不能宣称普遍验证完成。

## 历史实测摘要（不随包分发）

作者的历史项目曾进行约两分钟的合并回归，以及 63 条字幕、121.2 秒的图文承接/堆叠修复。记录包含全文问题审阅、前中后快照、实际成片抽帧、相交区间、布局修复和对比报告。这些历史原声、工程和成片不包含在本包中，也不构成包内可复跑的测试。

其中一轮先通过一般技术检查，仍被用户发现同屏堆叠，说明“有对象覆盖每句”与“成片表达合格”是两件事。复用逐句承接、生命周期与动态空间验收方法；不照抄旧图案、坐标、特定 0.1 秒阈值或品牌结构。历史相交扫描脚本绑定该期 DOM/GSAP，不是本包提供的通用检测器。

2026-10-11 的三轮本地回归方法和实际失败摘要见 [外部方法与实测](external-methods.md)。包括具体列举被概括、父子关系不清、支持与兑换混淆等反例。新 SRT 从 [自主制作](srt-autonomous.md) 进入同一流程。

当前工作区需要真实视频回归时，使用用户本次提供或明确授权复用的输入，在本期 `qa/` 重新生成证据。包内 `tests/` 只验证可复现的工具行为，不声称完成视频语义、视觉或听审验收。
