# 从语义分镜到可看的画面

在语义理解之后、批量排版之前读本文件。目标是让画面提供口播之外的识别、空间或变化信息。先给出实际画面，再判断设计是否成立；完整填写 JSON 不能代替这个过程。

## 1. 三种文字各有去处

| 层 | 承担什么 | 放哪里 |
| --- | --- | --- |
| 原声 / 原字幕 | 完整讲述与语气、原文时间依据 | 原音轨与字幕区；未经授权不改 |
| 屏幕表达 | 识别对象、区分关系、读懂数字 | 靠近对象的短标签、必要数字、精简观点；不是第二份逐句字幕 |
| 制作审阅 | 待核事实、来源、素材限制、审核结论 | 项目审阅文档；不自动上屏 |

“口播称”“据讲述资料”“本次尚未提供条款”“当前画面为……”等制作口吻，不写进面向观众的主体标签。**不设置每场自动调用的 note()/footnote() 模板。** 本次要求删除的注释不换个位置、颜色或说法回填。

上屏之前逐项问：没有这句话，观众会认错对象、数量、适用范围、当前观点或图示性质吗？若不会，删掉，重新排布留下的空位。不要同时使用长标题、整句解释、小字备注和字幕四层复述同一句话。标题也不是每场必备。

### 文字要有归属和承托

具体文字分级、三项/四项位置、图文组和逐步展开按 [文字角色与稳定版式](typography-layout.md) 实现。样式必须接入实际渲染；以下语义原则不能替代版式组件。

关键结论、受众评价和主角揭晓可以是主视觉的一部分；字幕存在不意味着上方只能留下几个零散名词。优先把对象与必要短句组织为一个读得懂的组，例如品牌名牌、结论框、条件容器。框的边界说明“这些信息属于一起”，而非为了每行文字都加装饰。

在本片米白风格中可用清晰浅底、细边框、适量内边距和文字层级；过复杂背景时承托须足够实，不随次要物件一起淡掉。一个框装一个命题或同一关系组，完整句仍由字幕承担。不要同时保留散落标题、角标、旁边名词和另一份相同的结论框；用框替换无归属散字，不在原堆叠上再加框。

框不是每个元素的强制外壳。地理图、流程、对比和实物可直接排布；卡片数量不是质量指标。短句是否有边界、依附哪个对象、为何此刻出现，都从本句焦点决定。

### 导航文字与内容步骤分层

“接下来进入实际操作”“这一节看三个方面”等总览和引导文字，承担的是告诉观众现在走到哪里。沿用本项目风格时，将它放进有清晰细边框、浅底和内边距的独立导航容器，与下面的步骤/对象留出层级和间距；不要让它像另一个无编号的步骤，也不要落成漂浮在角落的一句散字。用户截图中的红框用于指出问题，除非用户要求，不把标注红色当成设计色。

章编号和章名首次进入正文时，给它一个独立、能读清的章节状态：上一章主体收起，原编号与章名成为焦点，再进入本章第一句。编号不凭空重排，不能因“下面已有字幕”而省掉导航，也不要把章节切换做成一直常驻的底栏。短原声可在同一幕内完成“章牌→内容”的交接，不要求插入静音或固定长度片头。

导航先建立方向，随后步骤接过焦点；进入具体操作后，导航缩为章签或退场，只有仍有导向任务时保留。步骤已有编号、路径和对象就直接复用，不因加导航框重排成全屏卡片。普通对象标签、必要条件、数字和有意设计的引语仍按各自任务处理，不强制全部加框。

实际看图时遮住字幕，先判断哪一组是“现在进入哪部分”，哪一组是“这部分有哪些步骤”；再看进入步骤的中间态。二者混成同一排、框与步骤抢同等权重，或导航退场后留空洞，都需调整位置、尺度或生命周期。

需要区分币种、正负、数量关系或费用适用范围时，保留最短的必要标签，与对应数字成组。来源和核验过程留文档。概念图明显为插画时，不必反复标“示意”；虚构界面可能被认作真实操作、示例数据可能被认作实测时，明确区分或改用不会混淆的表达。

真实事实冲突另列给用户处理，不擅自把口播视频改成纠错课，也不把已知错误放大成有权威背书的图。需要改台词时提出具体句子和影响；用户当前只要求改 Skill 时，只记录冲突，不借机改录音或重做正片。

### 自我介绍前的开场：前0–10秒单独设计

Wise解说视频默认把自我介绍之前最先出现的一两句作为开场重点，尤其检查前0–10秒；不把整个自我介绍前的长段都当作一个开场。按原声实际时长编排，不插入额外话术或改变语速。

- 先找原稿里最值得继续看的**发现、具体问题、反差或变化**，写清观众在这几秒应该看见什么，以及继续看的理由。不要只把“有意思的策略”“值得关注”打成大字，旁边贴一张通用书本/图标。
- 按原稿支持的内容选择吸引方式：**反差**让前后/长短窗口的区别同时可见；**问题**先呈现具体卡点，再留下待解的关系；**发现**让分散样本聚成一条可识别规律；**结果预览**先亮出原稿已有的结果，再进入解释。选择能让观众产生明确问题的一种，不强制四种都用。悬念要在后续兑现，不以问号、闪光或动画标题替代对象和关系。
- 与本片已确认风格一致。动效集中服务一次发现或揭示，保持主次和阅读停留；不用更多图标、快速乱切、更多夸张文字来替代内容。稳定背景、署名和后续自我介绍沿用确认版本。
- 可以提前展示原稿已经支持的核心线索，但不添加文稿没有的收益、保证或夸大结论。历史样本的表现不能包装成今年必然获利；悬念提出后应在后续内容兑现。
- 在本期计划中记录`opening_hook`：原字幕范围、吸引点、可见的前态/发现动作/后态、与下一幕的接点。沿用真实对象与布局角色，不另建游离动画稿。
- 前10秒单独看前/中/后状态和连续短片：观众是否看见“发现了什么/为什么值得看”？若只有标题、通用配图和逐句标签，即使排版整齐也判开场表达不足。开场通过不代表全片语义通过；后续已获认可的画面不随开场重做。


## 2. 先决定观众看什么，再决定图放哪里

每个语义意群用几句具体话确定：

1. **主画面：** 这一段最值得看清的实体、地点、数值关系或过程是什么？
2. **图的任务：** 识别、定位、比较、解释机制，还是衔接话题？
3. **镜内展开：** 初始看到什么；说到关键动词时哪个已有对象怎样改变；最后留下什么参照？
4. **文案取舍：** 保留哪些短词，删掉哪些字幕已经承担的解释？
5. **素材依据：** 真图、可靠地理、生成实物、精确代码图形分别用在哪一层？

不要用“关系尚未展开→对象与关系可辨认”“根据口播渐次展开”“主体不与旁白冲突”等通用句批量填完计划。同样的表达若能替换任意行业、任意段落，就还没有做设计。停留应说明此时观众在识别或比较什么，不能统一写“保持当前场景”。

为最难或最容易退化成文字页的段落比较少量小构图：遮住字幕是否更容易理解、能否记住一个具体关系、现有素材与动作能否合理实现。选择有解释收益且制作代价相称的一版；无需给所有段落强行画多版。先有对象关系，后有坐标，不先摆三个框等内容来填。

## 3. 素材选择要对题，系列完成度要一致

### 表达任务决定素材

- **地理位置：** 用可靠地图轮廓、对应区域高亮、定位或局部放大。行政区域没有城市信息时不凭空钉一个城市。机构建筑只说明机构，不能替代“总部在某州/某地”的定位信息。地理形状从可靠地图数据或已有地图取得，不让生成模型自由猜轮廓。
- **主体身份：** 用准确标识和名称。品牌图原样保留；承托和大小可协调，不为了统一配色重绘 Logo。
- **实物 / 抽象产品：** 实物质感帮助识别和记忆；选择能表现本句区别的组合。股票凭证、成组资产/基金组合、带合约结构的文件应有可见差别，不用同一纸张换标签冒充理解。
- **数值与关系：** 坐标、比例、括号、路径、连线适合代码精确绘制。没有必要把它们都生成成光栅插图。
- **真实产品与操作：** 用真实界面/产品资料。没有材料时可完成概念说明，不能编造按钮、收益数据或品牌功能截图。

### 同组看起来必须像同一次设计

先用图像工具查看 [券商设备](../assets/visual-anchors/broker.png)、[银行](../assets/visual-anchors/bank.png)、[钱包](../assets/visual-anchors/wallet.png)、[凭证](../assets/visual-anchors/certificate.png) 中最相关的 1–2 张；材质参考不等于照抄主体。

保持米白、深海军蓝、少量香槟金的既定物件风格：真实厚度、可辨轮廓、轻微三分之四视角、柔和短阴影。品牌原色与地图精确线条可自然共存。具体构图参考 [已接受的流程帧](../assets/visual-anchors/accepted-flow.png)，继承其实物与关系的一致性，不把四张卡变成全片模板。

系列一致性落实到本期已有样式源和设计锁定记录：继承确认背景/署名、字体层级、物件材质/光向、强调色含义及常用运动节奏。强调色用于当前焦点或特定关系时，同片沿用该含义；品牌原色不随之改写。构图随叙事变化，不以逐镜同布局维持系列感。

同一语义层的主物件对照材质、光向、视角、轮廓复杂度、视觉重量、显示尺度。已有精致 3D 凭证，另两项缺图时，记录为**缺少同组主视觉**并按授权补齐；不得用几根 SVG 线条套白卡后标记“素材已齐”。已有授权就自行补齐，不再反复问同一缺口。

线框/SVG 很适合连线、曲线、刻度及次要符号；是否适合作主图取决于本片已选语言。不要把“所有东西都做成 3D”写成普遍规则，也不能为了统一而退化已认可素材。

新生成物件优先独立透明资产，文字与准确标识单独排版，便于重新摆放和跨句复用。需要内部相对运动时，生成前先明确可动部件；只需整体入场则不强行拆件。具体素材到动画的交接见 [设计到动效](design-to-motion.md)。不要生成一张带满文字的整页海报，再把它当作可编辑分镜。

## 4. 构图跟着叙事任务变化

以下是选择方向，不是每片必须集齐的模板：

| 叙事任务 | 空间与展开 | 检查重点 |
| --- | --- | --- |
| 主角揭晓 | 一个主体先建立，相关属性在其周围有节奏出现 | 第一眼有焦点，揭晓前不过早泄露重点 |
| 地点 / 时间 | 全域→局部定位，或稳定时间参照上的回溯/推进 | 观众能定位，而非只看到替代图标 |
| 产品列举→规则分组 | 同组物件先识别，后按费用/归属重排为有含义的组 | 同一物件延续，组与规则一起变 |
| 流程 / 传递 | 主体与载体分开，沿有依据的路线移动 | 有出发、到达与接收反馈 |
| 包含 / 保护范围 | 外层与子集、范围内外的空间区分 | 数量不被错误相加、对象不串层 |
| 前后变化 | 保留坐标或锚点，变化实际对应原文维度 | 不拿弹跳/淡入代替趋势变化 |
| 定义 / 总括结论 | 旧细节退场或收为必要参照，定义对象与简短结论构成一个独立焦点 | 不能把结论挂在仍占主场的上一句流程下方；独立聚焦不等于无依据换成另一页大字 |

**尺度先服从关系。** 讲一个主体及其条件/证据时，用主辅构图，主体在可见轮廓、位置或对比上先被看见，辅助项靠近对应部位并留出阅读空间；讲同级方案、前后结果或数量比较时，采用共享尺度、基线和相当视觉重量，避免用一大一小暗示未经支持的优劣。数值图的长度/面积编码不能为突出重点任意放大。细节需要辨认时局部放大或裁切，并保留必要参照；不把精细主图缩成缩略图再靠标签解释。不规定主物件必须占屏幕的固定比例。

并列合理时可以并列、卡片有归组作用时可以保留。问题是把所有内容都强塞进同宽白卡和从左到右的模板。连续出现同构镜头时，检查是否只换图、换字；数据连续演进需要稳定同构时则保留，不为变化而变化。

**并列项先验证是否同级，再平衡布局。** 同级五项可选对称的环绕、居中分行、等距带状等组织；按实际物件轮廓统一视觉尺度、标签基线和外围空隙，不把第五项随手塞到最右下角，也不只让图片文件框等宽。逐项讲述可临时强调当前项，列举结束时回到平衡集合。若存在上下级、主次或两种不同性质，应先分组，不能为了对称把它们强行拉平。

结论句进入时检查“第一眼看见的还是上一句话吗”：若是，先结束旧组、放大真正的结论关系或将对象收为一个清晰集合。无需每句硬切新幕，但必须有本句自己的可辨状态。

可见内容成组后再确定位置：**整页重量 → 组间距离 → 组内对齐**。测量透明图片的实际可见轮廓，不仅看文件方框。相关物件、短词和数据贴近，不相干组留出空隙。背景地球是布景层，不参与主体排序，也不占一个正文栏位。正文按整幅画布平衡，可覆盖地球区域，以必要承托保持对比；不要从地球边缘推导正文只准占左半幅。背景文件默认复用，用户明确要求调整位置时按新决定做变体，具体控制见制作控制。

## 5. 动作是句间关系，不是装饰清单

给主要动词一组可观察变化：对象谁移动、什么保持不动、结果在哪里、文字如何随对象走。比如列举之后讲费用：已经出现的产品保留，归为同一费用范围的两个对象靠拢，费用短词从该组出现；另一个保持分开。不是先排三图，再在底部新增三块说明。

重点用“铺垫 → 揭示 → 稳定”组织：先留下判断所需的对象/参照，关键动词处完成一个主要变化，再给结果稳定阅读。主指标可先成为焦点，随后拆解构成与必要细节；原稿需要先解释前提时不倒置因果。箭头、下划线或局部高亮贴近正在解释的部位，完成定位后退出或稳定，不让全屏同时争抢注意。

同一时段优先一个承载含义的主动作；标签、关系线等跟随它的进展，延后量依原声和识别需要决定，不统一套延迟。交接保留下一句确需的对象或位置锚点，结束旧动作后接入新焦点，避免整组重新弹入。阶段数与时间由原声决定，没有变化的列举可以稳定展示；不把弹跳、粒子或运动数量作为质量指标。引导句可以预置相关主体，不能只剩孤零零标题。

避免全片统一 `opacity:0→1, y:16→0, 450ms`。淡入可用于进场，但需要画出的“聚合、传递、回溯、分组、增多、趋近”必须改变对应关系。保留已选固定开场，不为了新规则重新设计。制作时将这里的意图转成 [可观察状态和原声落点](design-to-motion.md#3-把动词变成可观察的状态差异)，不以动作文案代替实际验证。

## 6. 批量制作前先跑视觉小闭环

从新输入中选有代表性的镜头：至少覆盖本片真正存在的主要难点（例如主视觉、关系变化、地点/数据），不以固定三镜或固定比例代替选择。出少量真实 PNG 和关键展开态，使用最终背景、真实素材与预计显示尺度。

打开 PNG，与已接受参考并排看；另保存并打开用户实际播放器尺寸的预览 PNG（未知时用约960像素宽并记录），不是只缩放代码中的字号。对照该帧的 `target_caption_id/time_ms` 读原句，先记第一眼实际看到的对象/关系，再与计划焦点比较。用具体判断回答：

- 遮住字幕还能认出主要对象/地点吗？细节是否只有看标签才知道？
- 图是否增加了理解，而非只是贴在字幕上方的名词贴纸？
- 同组主物件的完成度是否相容？主辅关系能否第一眼分清，同级比较有无被大小误导？细节在实际播放器尺度还能识别吗？
- 视线先看哪里再到哪里？前一句已讲完的载体会不会仍抢重点？文字属于哪一个对象/命题，是否近邻且有承托？
- 当前口播讲子项时，总额/大容器是否仍抢走重点？多个主角是共同完成比较/关系任务，还是未做取舍？逐一核对 retain 的理由与实际物件，不把理由写错也当已验收。
- 去掉字幕后，当前受众、条件或评价的新增意思是否仍有可辨状态？只保留一个泛用设备是否在假装覆盖？
- 前景重心是否由内容决定，还是被背景装饰挤到一侧？这种偏置有无当前叙事理由？
- 前、中、后态是否真正延续；是否有静态好看但展开时空洞/拥挤的问题？
- 是否有制作备注、重复字幕、无依据的新事实，或被用户删除的内容回填？

发现问题只改对应层：含义、素材、构图、文案、时机。保存前后图和一句具体差异，再以同一播放尺寸复查；记录实际文件、尺寸、原句、观察到的焦点及通过/失败/未验证，保留已经有效的部分。若自动制作已授权，内部完成这轮，不增加机械批准步骤。用户要求本轮只升级 Skill，则只在隔离测试目录做规则演练/静态样张，不改正片、不导出整片。

静态方向获认可后，将实际资产/背景哈希、设计源与关键布局依据记入本期既有状态，按 [静态到动态的交接](design-to-motion.md#1-把静态批准绑定到具体产物) 继续。批准仅覆盖其实际范围，不能自动推为动态、声音或完整文稿已通过。

**这道检查独立于技术验收。** “无碰撞”“字幕都有对象”“渲染成功”都不能填为审美通过。可以如实写“技术通过，视觉未通过”；审阅者看过实际图才能记录结果。不能用凭空的“90 分”“80%完成”替代证据。

## 7. 可复用失败触发器

发生以下情况，回到相应设计层检查，不能直接批量导出：

- 多段共用同一句 meaning/action/acceptance，或每条字幕绑定整场所有对象。
- 多数镜头只是标签和图标换位，关键谓词没有实际动作。
- 重要地点没有地理信息；实物/主体只有近似替代物。
- 同组精致实物与临时线框图充当同等主角。
- 几乎每场都有一条与字幕并行的“说明/风险/资料”横条。
- 前景只靠白框填满屏幕，删除框后内容仍无组织。

先运行 `scripts/audit_visual_plan.py PLAN.json` 获取可自动发现的候选，再实际看图判定。脚本只发现结构性退化，不负责判美，也不会因为没有告警就给设计通过。将证据和修复写项目 `design-review.md`，不把本期品牌、数字和坐标固化成新模板。
