本个人完整版沿用已确认背景：浅蓝海洋、暖白地貌，地球倾斜23.4°，180秒一圈，球心(1640,470)，半径414px；陆地装饰光点、底部三层山峦保持原版。光点不是实际城市或用电数据。

index.html 与 globe.js 的画面代码按原版保存，图片未修改。运行前需要 GSAP 3.14.2，按仓库 README 准备 assets/gsap.min.js；第三方运行库不随仓库提交。manifest.json 记录随包源文件哈希。
