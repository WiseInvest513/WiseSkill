仅适用于品牌合作视频。左上为真实品牌标识/名称、细分隔线和本期短主题；右上为用户原头像署名。继承 C 横排、半透明白底、细金线和紧凑圆角。

1920×1080 基准：左上 (76,30)，高57.37px，与右上原署名 (1634,30)、210×57.37px 同高。左侧宽度随内容自然展开，不强行压成210px；主品牌25px，主题23.5px。不随正文转场翻转或放大。

`brand-header.html` 是占位模板，品牌和主题必须由本期实际素材替换；`brand-header.css` 是 C 小尺寸样式。字体使用本片已加载的 Wise 字体。不要将 OKX 当成其他品牌的默认标识。

本期 OKX 原件带四边透明留白，示例CSS用内部裁切框显示真实标识。换品牌时按其原始透明边界调整图标适配，保留完整标识比例，不照搬 OKX 的裁切参数。复用经确认的品牌字标时，可替换整个 `.bh-brand` 内容，避免重复写名称。

在全画幅及960px缩放预览中检查两角同高、顶部对齐、文字完整和不遮挡正文。布局批准来自上述用户决定，样片内容另行审核；不因本模板改动旧成片。
